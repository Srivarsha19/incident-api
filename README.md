# Incident API

A production-oriented incident management API that evolves from
log analysis into an AI-powered incident investigation system.

## Goal

Build a Python backend application that can:

- Analyze application logs
- Create and manage incidents
- Store incident data
- Authenticate users
- Provide APIs for incident investigation
- Use AI/RAG to assist with incident analysis

## Planned Stack

- Python
- FastAPI
- PostgreSQL
- Redis
- Docker
- Cloud Run
- PostgreSQL + pgvector
- LLM API
- RAG
